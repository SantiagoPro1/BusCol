# Observatorio del Comercio por el Puerto de Manzanillo

Proyecto integrador **Trusted Data Lab**: pronóstico y análisis del movimiento mensual de contenedores (TEU) en Manzanillo, Colima, comparado con otros puertos de México.

- Propuesta: [`docs/E0/propuesta.md`](docs/E0/propuesta.md)
- Ficha de entrega E0: [`docs/E0/ENTREGA.md`](docs/E0/ENTREGA.md)
- Capa Bronce: [`data/bronce/`](data/bronce/), capturada por [`extractor/puertos.py`](extractor/puertos.py) vía GitHub Actions
- Calidad (PSP): [`calidad/`](calidad/)

Fuente principal: Coordinación General de Puertos y Marina Mercante, *Informe Estadístico Mensual de los Puertos de México* (gob.mx). Uso académico; URL y fecha de cada consulta en `data/bronce/manifiesto.csv`.
